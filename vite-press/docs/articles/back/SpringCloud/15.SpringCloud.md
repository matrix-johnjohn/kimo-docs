## Nacos
nacos通过服务注册与发现中心构建动态配置管理平台;微服务启动时自动向 Nacos Server 注册,其他服务可通过服务名调用（支持 DNS 和 HTTP 方式）,支持健康检查、权重路由、集群分组等;集中管理所有微服务的配置文件（如 application.yml）,支持配置热更新（无需重启服务）、灰度发布、历史版本回滚、监听变更等;

## Sentinel
sentinel主要用于流量控制,熔断服务,系统自适应保护,热点参数限流;

## Seata
seata负责处理分布式事务解决方案,解决微服务架构下跨多个数据库的数据一致性问题;
