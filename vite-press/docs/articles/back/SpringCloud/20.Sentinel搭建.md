# Sentinel搭建


Sentinel是阿里巴巴开源的一款服务保护框架,Sentinel的核心库可以独立运行于一个单独的环境之中,所以你可以直接将sentinel的jar包运行在任何环境之下;<a href="https://github.com/alibaba/Sentinel/releases/download/1.8.8/sentinel-dashboard-1.8.8.jar">点击安装</a>

## 依赖安装
在你的微服务模块下添加sentinel的依赖,用于连接sentinel-dashboard的控制台;
```` xml
<!--sentinel-->
<dependency>
    <groupId>com.alibaba.cloud</groupId> 
    <artifactId>spring-cloud-starter-alibaba-sentinel</artifactId>
</dependency>
````

## 配置文件
修改配置文件application.yml
```` yml
spring:
  cloud: 
    sentinel:
      transport:
        dashboard: localhost:8090 #sentinel的url
````

## 控制台运行
```` bash
java -Dserver.port=8090 -Dcsp.sentinel.dashboard.server=localhost:8090 -Dproject.name=sentinel-dashboard -jar sentinel-dashboard.jar
````
