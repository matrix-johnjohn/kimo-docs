## 引入依赖
在`pom.xml`安装`java-mail`的依赖
````xml
<!--JavaMail-->
<dependency>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-starter-mail</artifactId>
</dependency>
````

## 配置文件
在`application.yaml`中引入配置;
```` yml
spring:
  application:
    name: email-service

  mail:
    username: 13929944553@163.com
    password: RHSzTpKJ3EBZvqhF
    host: smtp.163.com
````

## 创建实例
创建`java-mail`的实例,方便用于发送邮件;
````java
@Autowired
private JavaMailSender javaMailSender;
````

## 发送邮件
封装邮件实体,之后用`java-mail`的实例发送到指定邮箱;
````java
@Test
void contextLoads() {
    SimpleMailMessage mail=new SimpleMailMessage();

    mail.setSubject("邮箱标题");

    mail.setText("内容:验证码为RHSzTpKJ3EBZvqhF,请收好");//设置邮箱内容

    mail.setTo("13929944553@163.com");

    mail.setFrom("13929944553@163.com");

    javaMailSender.send(mail);
}
````
