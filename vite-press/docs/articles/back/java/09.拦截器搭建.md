# 拦截器搭建
拦截器是SpringMVC中的一种过滤器,用于拦截请求,并做相应的处理,比如权限验证,日志记录,数据转换等等;


## 创建拦截器
创建拦截器类,实现HandlerInterceptor接口;

```` java
import jakarta.servlet.http.HttpServletRequest;
import jakarta.servlet.http.HttpServletResponse;
import org.skyhub.common.domain.po.User;
import org.skyhub.common.utils.UserContext;
import org.springframework.web.servlet.HandlerInterceptor;

public class UserInterceptor implements HandlerInterceptor {//拦截器
    
    @Override
    public boolean preHandle(HttpServletRequest request, HttpServletResponse response, Object handler) throws Exception {
        System.out.println("interceptor:设置用户");

        System.out.println(request.getHeader("passwd"));

        String username=request.getHeader("username");

        User user=new User();

        user.setUsername(username);

        UserContext.setUser(user);

        return true;
    }
    
    @Override
    public void afterCompletion(HttpServletRequest request, HttpServletResponse response, Object handler, Exception ex) throws Exception {
        System.out.println("interceptor:清除用户成功");
        UserContext.clear();
    }
    
}
````

## 注册拦截器
实现`WebMvcConfigurer`接口,将自定义的拦截器注册到SpringMVC中;
```` java
import org.skyhub.common.interceptor.UserInterceptor;
import org.springframework.boot.autoconfigure.condition.ConditionalOnClass;
import org.springframework.context.annotation.Configuration;
import org.springframework.web.servlet.DispatcherServlet;
import org.springframework.web.servlet.config.annotation.InterceptorRegistry;
import org.springframework.web.servlet.config.annotation.WebMvcConfigurer;

@Configuration
@ConditionalOnClass(DispatcherServlet.class)
public class InterceptorConfiguration implements WebMvcConfigurer {

    @Override
    public void addInterceptors(InterceptorRegistry registry) {
        System.out.println("interceptor启动");
        registry.addInterceptor(new UserInterceptor());
    }

}
````
