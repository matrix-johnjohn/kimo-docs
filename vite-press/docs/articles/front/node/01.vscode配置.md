# vscode的配置

## 执行策略

### 查看当前执行策略

在powershell中查看当前执行策略

````
Get-ExecutionPolicy
````



### 更改执行策略

更改执行策略为 `RemoteSigned`

````
Set-ExecutionPolicy RemoteSigned
````
