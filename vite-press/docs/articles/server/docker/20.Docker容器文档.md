## Docker镜像和容器文档



## MySQL镜像

### 部署方式

#### 镜像拉取

从`DockerHub`中拉取镜像;

````
docker pull mysql:latest
````

#### 容器开启

````
docker run --name mysql \
  -e MYSQL_ROOT_PASSWORD=123456 \
  -e MYSQL_USER=matrix \
  -e MYSQL_PASSWORD=123456 \
  -p 3306:3306 \
  --restart unless-stopped \
  --network custom-net \
  -d mysql \
  --character-set-server=utf8mb4 \
  --collation-server=utf8mb4_unicode_ci
````



## Nginx镜像

### 部署方式

#### 镜像拉取

从`DockerHub`中拉取镜像;

````
docker pull nginx:latest
````

#### 容器开启

````
docker run --name nginx \
  -p 80:80 \
  -v html:/usr/share/nginx/html \
  -v config:/etc/nginx/conf.d \
  --restart unless-stopped \
  --network custom-net \
  -d nginx
````



## Redis镜像

### 部署方式

#### 镜像拉取

从`DockerHub`中拉取镜像;

````
docker pull redis:latest
````

#### 容器开启

````
docker run -d \
  --name redis \
  --restart=unless-stopped \
  -p 6379:6379 \
  -v /opt/redis/data:/data \
  redis:latest \
  redis-server --appendonly yes
````



## Minio镜像

minio是一个可供oss本地对象存储服务;

> 目前minio已经不再提供免费开源服务,如果`DockerHub`官方仓库已经没有可拉去的镜像;
>
> 如果DockerHub已经没有minio的镜像且需要minio用于非商业用途可以到kimo的网站中安装;
>
> 下载地址:<a href="">安装地址</a>;

### 部署方式

#### 镜像拉取

从`DockerHub`中拉取镜像;或者到up的网站中安装

````shell
minio/minio:RELEASE.2025-04-22T22-12-26Z
````

#### 容器开启

基于镜像开启一个容器;

````shell
docker run -d \
  --name minio \
  -p 9000:9000 \
  -p 9001:9001 \
  -e "MINIO_ROOT_USER=admin" \
  -e "MINIO_ROOT_PASSWORD=jillleeismyhost" \
  -v /mnt/minio/data:/data \
  -v /mnt/minio/config:/root/.minio \
  --restart unless-stopped \
  minio/minio:RELEASE.2025-04-22T22-12-26Z \
  server /data --console-address ":9001"
````

#### 依赖集成

#### 安装依赖

`maven`项目集成`minio`;

````xml
<dependency>
  <groupId>io.minio</groupId>
  <artifactId>minio</artifactId>
  <version>8.4.3</version>
</dependency>
````

`minio`的配置类:

````java
import io.minio.MinioClient;
import lombok.AllArgsConstructor;
import lombok.Data;
import lombok.NoArgsConstructor;
import org.springframework.boot.context.properties.ConfigurationProperties;
import org.springframework.context.annotation.Bean;
import org.springframework.context.annotation.Configuration;

@Data
@Configuration
@ConfigurationProperties(prefix = "minio.oss")
@NoArgsConstructor
@AllArgsConstructor
public class MinioConfig {

    private String accessKey;
    private String secretKey;
    private String url;
    private String bucketName;

    @Bean
    public MinioClient minioClient(){
        return MinioClient.builder()
                .endpoint(url)
                .credentials(accessKey,secretKey)
                .build();
    }
}
````

`minio`工具类:

````java
import com.heima.config.MinioConfig;
import io.minio.MinioClient;
import io.minio.PutObjectArgs;
import io.minio.errors.*;
import org.springframework.beans.factory.annotation.Autowired;
import org.springframework.stereotype.Service;
import org.springframework.web.multipart.MultipartFile;
import java.io.IOException;
import java.io.InputStream;
import java.security.InvalidKeyException;
import java.security.NoSuchAlgorithmException;

@Service
public class MinioUtils {

    @Autowired
    private MinioClient minioClient;

    @Autowired
    private MinioConfig configuration;//自定义配置类


    /**
     * @param file     文件
     * @param fileName 文件名称
     * @Description 上传文件
     */
    public void upload(MultipartFile file, String fileName) {
        // 使用putObject上传一个文件到存储桶中。
        try {
            InputStream inputStream = file.getInputStream();
            minioClient.putObject(PutObjectArgs.builder()
                    .bucket(configuration.getBucketName())
                    .object(fileName)
                    .stream(inputStream, file.getSize(), -1)
                    .contentType(file.getContentType())
                    .build());
        } catch (ErrorResponseException e) {
            e.printStackTrace();
        } catch (InsufficientDataException e) {
            e.printStackTrace();
        } catch (InternalException e) {
            e.printStackTrace();
        } catch (InvalidKeyException e) {
            e.printStackTrace();
        } catch (InvalidResponseException e) {
            e.printStackTrace();
        } catch (IOException e) {
            e.printStackTrace();
        } catch (NoSuchAlgorithmException e) {
            e.printStackTrace();
        } catch (ServerException e) {
            e.printStackTrace();
        } catch (XmlParserException e) {
            e.printStackTrace();
        }
    }
}
````
