## 字符串暴力匹配
```` c
int match_bf(char* s1,char *s2){
    int i=0,j=0;
    while(i<strlen(s1)&&j<strlen(s2)){
        if(s1[i]==s2[j]){
            i++;
            j++;
        }else{
            i=i-j+1;
            j=0;
        }
    }

    return (j==strlen(s2))?i-j:-1;
};
````
