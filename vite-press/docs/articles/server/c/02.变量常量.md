## 宏
宏是C预处理器提供的一种文本替换机制,它在编译之前对源代码进行扫描和替换,因此宏本身不会占用程序运行时的内存;
```` C
#include<stdio.h>
#define PI 3.141592653589//宏

int main() {
	printf("%.2f",PI);
	return 0;
} 
````

## 变量和常量
变量本质是一块内存区域的别名,用来存储程序运行时所需要的数据;当你定义一个变量时,编译器会根据数据类型分配相应的内存空间;

```` C
#include<stdio.h>

int main() {
	int age = 20;//变量赋值
	const double PI = 3.141592653589;//常量赋值
	printf("%d %.2f", age,PI);
	return 0;
} 
````


## 内存分配与初始化
C通常情况下不会自动把分配到的内存。如果定义变量时没有显式赋值，变量里存的不是`0`，而是内存原本残留的随机数据，也就是所谓的`垃圾值`（Garbage Value）
