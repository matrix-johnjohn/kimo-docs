## 树
`树(tree)`是n个结点的有限集,当n=0时,该树会被成为`空树`,当n>0时,该树为`非空树`;<br>
在`非空树`T当中,有且仅有一个`根节点`;<br>
除`根节点`以外的其余结点可以分为m个互不相交的有限集T1,T2,T3...Tm,其中一个集合本身又是一棵树,成为`当前根节点`的子树;
![](https://raw.githubusercontent.com/matrix-johnjohn/kimo-docs/refs/heads/main/images/articles/server/c/data-struct/tree/01.tree.png)

## 树的基本术语
`结点`是指树中的每一个独立的存储单元;<br>
`结点的度`是指当前结点的拥有的子树;<br>
`树的度`是指树中结点最多的子节点的结点的度<br>
`叶子、终端节点`是指度为0的结点<br>
`分支结点、非终端结点`是指度不为0的结点<br>
`兄弟结点`是指同一个双亲结点的孩子结点<br>
`堂兄弟结点`是指同一层的结点互为堂兄弟结点<br>
`层次`是指树的当前结点所处的层级数<br>
`深度`是指树的结点的最大层次<br>
`森林`是指互补相交的树的集合<br>
![](https://raw.githubusercontent.com/matrix-johnjohn/kimo-docs/refs/heads/main/images/articles/server/c/data-struct/tree/02.tree.png)

## 二叉树
二叉树(Binary Tree)是n个结点所构成的集合,当n=0时,该树会被成为`空树`,当n>0时,该树为`非空树`;<br>
若该二叉树T为非空树,那么该二叉树有且仅有一个`根节点`,并且根节点以外的其余结点分为两个互不相交的子集T1和T2,分为T的左子树和右子树,且T1和T2都是二叉树;
![](https://raw.githubusercontent.com/matrix-johnjohn/kimo-docs/refs/heads/main/images/articles/server/c/data-struct/tree/03.tree.png)

## 二叉树的基本术语

### 满二叉树
每一层上的节点数都是最大节点数,每一层i的结点树都具有最大值2^(i-1);
