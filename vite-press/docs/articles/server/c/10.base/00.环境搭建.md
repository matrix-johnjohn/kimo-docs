## 配置 C++ 环境

### 编译器安装
使用apt命令安装编译器集合

```` bash
sudo apt update
sudo apt install build-essential gdb
````

### CMAKE安装
CMake 是一个跨平台的构建工具,用于管理项目的编译过程
```` bash
sudo apt install cmake
````

### 版本检查
检查所需依赖的版本
```` bash
gcc --version 
g++ --version 
gdb --version 
cmake --version
````
