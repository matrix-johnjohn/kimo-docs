## 定义枚举
如果一个变量只有几种可能的赋值,那么使用枚举类型来定义是合适的;
````C
#define _CRT_SECURE_NO_WARNINGS
#include <stdio.h>
#include <stdlib.h>
#include <string.h>

typedef enum Gender {
    male = 1, female = 2, unknown = 3
}Gender;

int main() {
    Gender gender = male;
    printf("%d", gender);
    return 0;
}
````
