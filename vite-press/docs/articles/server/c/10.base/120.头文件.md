头文件是一种用来包含一些公共信息的文件,比如函数的声明,宏定义,结构体,共用体,枚举等;之后在工程中的文件就可以引用该头文件;

![网络不好,图片显示不了](https://raw.githubusercontent.com/matrix-johnjohn/kimo-docs/refs/heads/main/images/articles/server/c/head/1.head.png)

在编译之前,对源文件进行一些预处理,将宏定义替换为对应的值,将包含的头文件插入到源文件当中,根据条件编译指令来决定是否编译某部分代码,取出源代码的注释,简单的说就是对源文件进行一些`文本替换`;<br>

编译阶段将预处理之后的源文件转换成汇编代码,对汇编代码进行语法检查,类型检查等;<br>

汇编就是把编译生成的汇编代码再经一步转换成机器码,然后生成一个目标文件,通常是`.o`;<br>

链接阶段就是把所有的目标文件,和使用的库文件链接在一起,最终形成一个可执行文件;<br>


````c
#pragma once
typedef enum Gender {
	male = 1, female = 2, unknown = 3
}Gender;

typedef struct Teacher{
	int id;
	char *name;
	Gender gender;
	int age;
	double salary;
}Teacher;

void TeacherPrintln(Teacher* teacher){
	printf("ID: %d\n", teacher->id);
	printf("Name: %s\n", teacher->name);
	printf("Gender: %d\n", teacher->gender);
	printf("Age: %d\n", teacher->age);
	printf("Salary: %.2f\n", teacher->salary);
}
````
