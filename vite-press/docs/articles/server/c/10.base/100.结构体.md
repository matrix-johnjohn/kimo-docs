## 结构体
结构体是一种自定义的数据类型,可以包含多个不同类型的成员变量;

## 结构体
为一个结构体命名;
````C
typedef struct Teacher
{
    int id;
    char* name;
    int age;
    int salary;
} Teacher;
````
