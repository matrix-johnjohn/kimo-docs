## 格式化输出函数
这是C语言中最强大、也是最常用的输出函数;它允许你按照指定的模板格式输出各种类型的数据,需要配合格式说明符号将指定数据输入到控制台中;
````c
int printf(const char *format, ...);
````

## 字符输出
当你只需要输出单个字符时,使用这个函数会比 printf 更轻量、效率更高;
````c
int putchar(int c);
````

## 字符串输出
专门用于输出一整串字符;
````c
int puts(const char *s);
````
