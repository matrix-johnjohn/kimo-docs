在C语言中,复合语句(Compound Statement)是指用一对花括号`{}`包裹起来的一组语句,它也被称为`block`;对于编译器而言,`{...}`内的多条语句会被打包成一个逻辑单元;


## 生命周期
复合语句内定义的变量仅在语句内有效,语句外被定义的值也可以在复合语句内部进行修改;
````c
#include<stdio.h>
#include<stdlib.h>

void test(){
    {
        int a=20;
        printf("%d",(a));
    }
}

int main(){
    test();
    return 0;
};
````

## 复合语句的应用
符合语句是`条件判断语句`,`循环语句`的能够实现多行逻辑控制的关键组成部分;
````c
// for 循环
for (int i = 0; i < 3; i++) {
    printf("第 %d 次循环\n", i);
    process_data(i);
}

// while 循环
while (input != 0) {
    sum += input;
    count++;
    scanf("%d", &input);
}

// if-else
if (score >= 90) {
    grade = 'A';
    printf("优秀！\n");
} else if (score >= 80) {
    grade = 'B';
    printf("良好\n");
} else {
    grade = 'C';
    printf("继续努力\n");
}
````
