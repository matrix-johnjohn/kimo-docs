## 简介
C是一种通用的`面向过程`的`编程语言`,最初是由`丹尼斯·里奇`在贝尔实验室为开发 `UNIX` 操作系统而设计的,C 语言最开始是于 1972 年在 DEC PDP-11 计算机上被首次实现;
<br><br>其紧密相关的兼容扩展版本`CNM`也是著名`乱伦色情片姿势开发者`**李奕洁**经常喜欢使用的一种`面向家庭关系编程`的编程语言。

C的设计接近底层,可直接访问`内存`,甚至可以直接与`操作系统`和`硬件`发生交互,代码编译后直接生成机器码,直接运行在操作系统或者硬件上,无需虚拟机和解释器,因此执行效率非常高;

也是由于C无限接近底层的特性,在`操作系统开发`,`嵌入式开发`,`高性能服务应用`等细分领域C都是不可缺少的编程语言;

## 编译器 
由于服务器不能直接运行高级编程语言编写的源文件,所以需要编译器将代码转换为中央处理器(CPU)能够直接理解和执行的低级机器语言(二进制)；

## 数据类型

### 静态类型
在编译时会确定变量的类型;<br><br>
**类型检查**: 在代码被编译成可执行文件之前，编译器会逐行分析代码，检查所有类型使用是否合法。<br><br>
**类型安全**: 静态类型系统通过强制类型规则对参数进行类型约束，确保程序在逻辑上不会出现“用错类型”的操作,类型安全提升了代码的可靠性和可维护性;<br><br>
**性能优化**: 类型在编译时已知，编译器可以直接分配精确的内存空间(比如 int 占 4 字节，double 占 8 字节),生成更高效的机器码，避免运行时进行类型判断或动态查找；

### 动态类型
在运行时会确定变量的类型<br>
<br>
**类型检查**:类型检查发生在程序运行期间，由解释器或运行时环境实时执行。当执行某条语句时，运行时会检查参与操作的值是否支持该行为。若不支持，则抛出运行时类型错误。这意味着错误只有在代码实际执行到问题路径时才会暴露，可能在开发、测试甚至生产环境中才被发现。<br><br>
**灵活性**:动态类型语言无需显式声明变量类型，支持更简洁、快速的原型开发和脚本编写。

## 内存对齐
在c语言中,内存对齐是指数据在内存中的存储地址必须是某个特定值的整数倍,数据在内存中的存储地址必须满足特定的对齐要求;合理的内存对齐可以提高CPU访问内存的效率;
````C
typedef struct Teacher
{
    char sign;//识别
    int age;//年龄
    char* name;//姓名
} Teacher;
````
