散列表的基本思想是查找元素记录的存储位置与关键字之间存在直接的对应关系;

## 哈希表结构
链式哈希表的结构
````c
typedef struct Node{
    int key;
    struct Node* next;
}Node;

typedef struct TableItem{
    int firstkey;
    struct Node* nextNode;
}TableItem;

typedef struct HashTable{
    struct TableItem* list;
    int length;
}HashTable,*HashTablePtr;
````

## 初始化哈希表
````c
Status initHashTable(HashTablePtr* HT){
    *HT=(HashTable*)malloc(sizeof(HashTable));
    (*HT)->list=(TableItem*)malloc(sizeof(TableItem)*hash_val);
    for(int i=0;i<hash_val;i++){
        (*HT)->list[i].firstkey=empty;
        (*HT)->list[i].nextNode=NULL;
    };
    (*HT)->length=0;
    return OK;
};
````

## 链地址法
获取哈希值后,查看该该索引下是否为空,如果为空,则直接将元素填入,如果非空,则填入当前索引的下一结点的地址;
```` c
Status put(HashTable* HT,int key){
    int index=hash(key);
    if(HT->list[index].firstkey==empty){
        HT->list[index].firstkey=key;
        return OK;
    }else{
        Node* p=(Node*)malloc(sizeof(Node));
        p->key=key;
        p->next=HT->list[index].nextNode;
        HT->list[index].nextNode=p;
    };
    HT->length++;
    return OK;
};
````
