## 线索二叉树的存储结构
````C
typedef struct TreeNode{
    int data;
    struct TreeNode *left;
    struct TreeNode *right;
    int Ltag;//0:左孩子,1前驱
    int Rtag;//0：右孩子,1后继
}TreeNode,*Tree;
````
