## 字符读取
读出`文本文件`中的第一个元素,读取错误或到达文件尾部则返回`EOF`;
````c
int fgetc(FILE *stream);
````

当你需要读取整个文本文件的时候,该机制的作用将会体现的非常完全;
````c
#include<stdio.h>
#include<stdlib.h>
#include<string.h>

int main(){
    FILE* fp=fopen("../tree.data","r");

    while (1){
        int c=fgetc(fp);
        if(c==EOF){
            break;
        }else{
            printf("%c",c);
        }
    }
    printf("\n");
    
    fclose(fp);
    return 0;
}
````

## 字符串读取
fgets最多读取n-1个字符,或直到遇到换行符`\n`或`EOF`;
````c
char *fgets(char *buf, int n, FILE *stream);
````
返回值和读取元素实际上是一致的,当你需要读取整个文本文件的时候,该机制的作用将会体现的非常完全;
````c
#include<stdio.h>
#include<stdlib.h>
#include<string.h>

int main(){
    FILE* fp=fopen("../tree.data","r");
    
    char buf[100];
    while(fgets(buf,100,fp)!=0x0){
        printf("%s",buf);
    }
    fclose(fp);
    return 0;
}
````

## 格式化读取
按格式从文件中解析数据,成功匹配并赋值的项目数,若在任何转换前遇到`EOF`,返回`EOF`;
````c
int fscanf(FILE *stream, const char *format, ...);
````


## 二进制读取
从流中读取nmemb个元素,每个size字节,存入ptr中,返回实际读取的元素个数;
````c
size_t fread(void *ptr, size_t size, size_t nmemb, FILE *stream);
````
