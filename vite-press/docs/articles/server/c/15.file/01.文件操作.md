在C语言中，文件操作是程序与外部世界交互的重要方式。无论是读取配置文件、保存用户数据，还是处理日志信息，都离不开对文件的读写操作。本文将带你从零开始掌握C语言中的基本文件操作。

## 文件指针
C语言通过`FILE`结构体来管理文件,所有文件操作都需要一个指向FILE的指针;
````c
FILE* p=NULL;
````

## 文件流
c语言通过`feof`判断文件流是否读到文件结尾,如果读到文件尾部则返回`非零值`,否则返回`0`;
````c
int feof (FILE *__stream)
````

## 打开文件
c语言通过`fopen`函数创建或者打开一个文件,这个函数会初始化类型`FILE`的一个数据对象,类型`FILE`包含了所有用来控制流的必要信息;
````c
FILE *fopen(const char *filepath, const const char *mode);
````

## 关闭文件
为了关闭文件,请使用`fclose`函数;指针释放成功后返回`NULL`,否则返回`EOF`;
````c
int fclose( FILE *fp );
````


## 文件使用方式
|  模式  |  描述  |
| ------ | ----  |
| r | 打开一个已经存在的ascii文本文件 |
| w | 往指定路径的ascii文件写入 |
| a | 往指定路径的ascii文件追加写入 |
| rb | 打开一个已经存在的二进制文本文件 |
| wb | 往指定路径的二进制文件写入 |
| ab | 往指定路径的二进制文件追加写入 |
