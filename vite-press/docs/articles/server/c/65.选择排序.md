## 直接选择排序
直接选择排序的思想是将数组在位置`[0,i-1]`看成是有序的,选择索引i后的最小值放在i这个位置,则`[0,i]`都是有序的;
````c
void swap(int* n1,int* n2){
    int tmp=*n1;
    *n1=*n2;
    *n2=tmp;
}

void selection_sort(int* a,int length){
    for(int i=0;i<length-1;i++){
        int min=i;
        for(int j=i+1;j<length;j++){
            if(a[j]<a[min]){
                min=j;
            };
        };
        if(min!=i){
            swap(&a[min],&a[i]);
        }
        
    }
}
````
