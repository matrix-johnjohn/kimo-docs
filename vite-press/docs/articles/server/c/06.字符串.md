## 字符数组
在很多编程语言当中是有字符串的,比如说`JAVA`,`Python`,`C++`,`Go`,`Rust`,`TypeScript`;<br><br>
而`C`的字符串本质上就是一个字符数组,字符数组的最后一个元素是一个空字符`\0`;
````C
#include<stdio.h>
#include<stdlib.h>
#include "main.h"

int main() {
	char c[] = {'H','e','l','l','o','\0'};
	printf("%s\n", c);
	return 0;
}
````
由于字符串本身就是个字符数组,而数组名本身就是一个指针常量,其存储的是数组的首地址;
````C
#include<stdio.h>
#include<stdlib.h>
#include "main.h"

int main() {
	char c[] = "hello";
	char* p = c;
	printf("%p\n", p++); //00000080BD90F584
	printf("%p\n", p++); //00000080BD90F585
	printf("%p\n", p++); //00000080BD90F586
	return 0;
}
````
