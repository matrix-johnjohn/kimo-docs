## 字符数组
在很多编程语言当中是有字符串的,比如说`JAVA`,`Python`,`C++`,`Go`,`Rust`,`TypeScript`;<br><br>
而`C`的字符串本质上就是一个字符数组,字符数组的最后一个元素是一个空字符`\0`;
````C
#include<stdio.h>
#include<stdlib.h>
#include "main.h"

int main() {
	char c[] = {'H','e','l','l','o','\0'};
	printf("%s\n", c);
	return 0;
}
````

由于字符串本身就是个字符数组,而数组名本身就是一个指针常量,其存储的是数组的首地址;
![](https://raw.githubusercontent.com/matrix-johnjohn/kimo-docs/refs/heads/main/images/articles/server/c/string/1string.png)
````C
#include<stdio.h>
#include<stdlib.h>
#include "main.h"

int main() {
	char c[] = "hello";
	char* p = c;
	printf("%p\n", p++); //0x80BD90F584
	printf("%p\n", p++); //0x80BD90F585
	printf("%p\n", p++); //0x80BD90F586
	return 0;
}
````

## 库函数

### 复制字符串
`strcpy(char *s1,char *s2)`是字符串标准库函数中的一个函数,复制字符串`s2`到字符串`s1`;`s1`所在的数组缓冲区总大小至少为`s2`的总大小多一个字节;
![](https://raw.githubusercontent.com/matrix-johnjohn/kimo-docs/refs/heads/main/images/articles/server/c/string/2string.png)
````C
#define _CRT_SECURE_NO_WARNINGS
#include <stdio.h>
#include <string.h>

int main() {
    char c1[6] = "";
    char c2[] = "HELLO";

	strcpy(c1, c2);
	printf("%s\n", c1);
    return 0;
}
````

### 拼接字符串
`strcat(char *s1,char *s2)`是字符串标准库函数中的一个函数,将`s2`拼接到`s1`末尾,而且`s1`的空间大小起码能够容纳字符串总大小+1;
````C
#define _CRT_SECURE_NO_WARNINGS
#include <stdio.h>
#include <string.h>

int main() {
    char c1[11] = "Hello";
    char c2[] = "World";
	strcat(c1, c2);

	printf("%s\n", c1);
    return 0;
}
````
