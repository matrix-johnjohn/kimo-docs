## 邻接表
邻接表(Adjacency List)是图的一种`链式存储结构`,在邻接表中,对图中每个顶点`Vi`建立一个`单链表`,把`Vi`相邻接的顶点放在这个链表中;
![](https://raw.githubusercontent.com/matrix-johnjohn/kimo-docs/refs/heads/main/images/articles/server/c/data-struct/graph/01.graph.png)
### 表头结点表
表头结点包括`数据域`和`链域`两部分,`数据域`用于存储顶点`Vi`的名称或有关信息,`链域`指向链表中的第一个结点;
![](https://raw.githubusercontent.com/matrix-johnjohn/kimo-docs/refs/heads/main/images/articles/server/c/data-struct/graph/02.graph.png)
### 边结点表
边界点包括`邻接点域`,`数据域`,`链域`三部分组成,`邻接点域`是与顶点`Vi`邻接的点在图中的位置,`数据域`存储和边相关的信息,如权值等,`链域`是与顶点`Vi`邻接的下一条边的结点;
![](https://raw.githubusercontent.com/matrix-johnjohn/kimo-docs/refs/heads/main/images/articles/server/c/data-struct/graph/03.graph.png)
