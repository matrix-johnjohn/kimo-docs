## 直接插入排序
直接插入排序的思想是将一条记录插入到当前有序数组`[0,i-1]`中,通过直接的线性查找在`[0,i-1]`中找到第一个比当前`key`值大的索引`j`,之后将该索引下的值放在`j`的前一位置;
````c
void insertionsort(int *a,int length){
    for(int i=1;i<length;i++){
        int key=a[i],j=i-1;
        while(j>=0&&a[j]>key){
            a[j+1]=a[j];
            j--;
        }
        a[j+1]=key;
    };
};
````

## 折半插入排序
折半插入排序的思想是通过二分搜索算法查在当前有序列表`[0,i-1]`中找到第一个比`当前元素i`大的索引`j`;
````c
int search_bin(int *a,int low,int height,int key){
    while(low<=height){
        int mid=(low+height)/2;
        if(a[mid]<key)low=mid+1;
        else if(a[mid]>key)height=mid-1;
    }
    return low;
};

void insertion_sort(int *a,int length){
    for(int i=1;i<length;i++){
        int key=a[i];
        int j=search_bin(a,0,i-1,key);
        for(int k=i;k>j;k--){
            a[k]=a[k-1];
        }
        a[j]=key;
    }
}
````
