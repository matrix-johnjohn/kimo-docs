## 链表的概念
在链表中,结点在存储器中的位置是任意的,即逻辑上相邻的数据元素在物理上不一定相邻;
![](https://raw.githubusercontent.com/matrix-johnjohn/kimo-docs/refs/heads/main/images/articles/server/c/data-struct/linearlist/3.linearlist.png)
<br>
指针,头节点,和首元结点;<br>
`头指针`是指向链表中的第一个结点的指针;`头节点`是在链表的首元结点之前附设的一个结点,数据域只放空表标志和表长等信息;`首元结点`是指链表中存储第一个数据元素的结点;
![](https://raw.githubusercontent.com/matrix-johnjohn/kimo-docs/refs/heads/main/images/articles/server/c/data-struct/linkedlist/02.linkedlist.png)

## 链表的结点
链表的结点是数据元素的存储映像,由`数据域`和`指针域`两部分组成;
![](https://raw.githubusercontent.com/matrix-johnjohn/kimo-docs/refs/heads/main/images/articles/server/c/data-struct/linkedlist/01.linkedlist.png)

## 链表的结构
定义一个链表,`LinkList L`为链表的头指针,L对应的结点变量表示链表上的每一个结点;
````C
typedef struct LNode {
	ElemType data;
	struct LNode* next;
} LNode, * LinkList;
````

## 链表的初始化
初始化一个空表,带头结点的单链表;<br>
生成新节点作为头节点,用头指针`list`指向`头节点`,`头节点`的`指针域置空`;
````C
LinkList initLinkList() {
	LinkList list=(LinkList)malloc(sizeof(LNode));
	if (list == NULL) {
		printf("/n");
		exit(EXIT_FAILURE);
	}
	list->next = NULL;
	return list;
}
````
````C
void InitLinkedList(LinkedList* L){
    *L = (LinkedList)malloc(sizeof(LNode));
    if (!*L) {
        printf("Memory allocation failed!\n");
        exit(EXIT_FAILURE);
    }
    (*L)->next = NULL;
}
````

## 判断链表是否非空
````C
int isEmptyLinkList(LinkList list) {
	if (list->next == NULL){
		return 1;
	}
	else {
		return 0;
	}

````

## 链表的销毁
````C
void DestroyLinkList(LinkList list){
	LNode* current;
	while (list != NULL) {
		current = list;
		list = list->next;
		free(current);
	}
}
````

## 链表的长度
从首元结点开始,一次计数所有结点;
````C
int LinkListLength(LinkList list){
	if (list == NULL) {
		fprintf(stderr, "Invalid LinkList Memory\n");
		exit(EXIT_FAILURE);
	}

	int length = 0;
	LinkList current=list->next;
	while (current!=NULL)
	{
		length++;
		current = current->next;
	}
	return length;
}
````

## 链表的查找
````C
LNode* LocateElem(LinkList list,ElemType elem){
	LNode* p=list->next;
	while (p&&p->value.id != elem.id){
		p = p->next;
	}
	return p;
}
````

## 链表的插入
````C
void InsertLinkList(LinkList list,ElemType elem,int index){
	
	int currIdx=0;
	LNode* p=list;
	
	while(p!=NULL&&currIdx<index){
		p = p->next;
		currIdx++;
	}

	LNode *s=(LNode*)malloc(sizeof(LNode));
	s->value=elem;
	s->next=p->next;
	p->next = s;
}
````

## 链表的删除
````C
void LinkListDelete(LinkList list, int index){
	int currIdx=0;
	LNode *p=list;
	while(p!=NULL&&currIdx<index){
		p=p->next;
		currIdx++;
	}
	LNode *q=p->next;
	p->next = q->next;
	free(q);
};
````
