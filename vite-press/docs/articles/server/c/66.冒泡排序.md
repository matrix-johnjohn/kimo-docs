## 冒泡排序
冒泡排序的思想是通过索引j与j+1进行交换的方式,将最大的元素放置在数组尾部,单次迭代后确保数组`[j,length-1]`范围中的元素是有序的;
````c
void swap(int* n1,int* n2){
    int tmp=*n1;
    *n1=*n2;
    *n2=tmp;
}

void bubble_sort(int* a,int length){
    for(int i=0;i<length;i++){
        for(int j=0;j<length-i-1;j++){
            if(a[j]>a[j+1]){
                swap(&a[j],&a[j+1]);
            }
        }
    }
}
````

## 冒泡排序运行过程
每次迭代指针`[j]`都会从索引0出开始查找;
![](https://raw.githubusercontent.com/matrix-johnjohn/kimo-docs/refs/heads/main/images/articles/server/c/data-struct/sort/bubble_sort/bubble_sort_01.png)

若数组索引`[j]`下的元素大于`[j+1]`的元素,则进行交换;索引`[j]`不断前进,直到索引`[j]`指向`[length-i-1]`为止,则数组范围`[j+1,length-1]`是有序的;
