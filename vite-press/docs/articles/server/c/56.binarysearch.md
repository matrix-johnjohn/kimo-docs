折半查找也称二分查找,是一种效率较高的查找方式,但是折半查找要求线性表必须采用顺序存储结构,而且表中元素按照关键字进行有序排序;

## 数据元素类型
```` c
typedef struct ElementType{
    int key;
    char data;
}ElementType;

typedef struct SeqTable{
    ElementType* r;//存储空间基地址
    int length;//表长
}SeqTable;
````

## 二分查找
折半查找每次查找都使查找范围缩小一半,与查找排序相比,很显然会提高查找效率;
```` c
int Search_Bin(SeqTable ST,int key){
    int low=0,height=ST.length;
    while(low<=height){
        int mid=(low+height)/2;
        if(ST.r[mid].key==key)return mid;
        else if(ST.r[mid].key>key)height=mid-1;
        else if(ST.r[mid].key<key)low=mid+1;
    };
    return -1;
};
````
