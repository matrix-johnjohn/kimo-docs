## 顺序表的定义
顺序表是用一组地址连续的存储单元依次存储线性表中的数据元素,从而使逻辑上相邻的两个元素在物理位置上也相邻;<br>
在顺序表中,每个元素的地址连续,类型相同,依次存放,可以根据索引随机存取;
