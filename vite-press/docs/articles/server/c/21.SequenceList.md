## 顺序表的定义
顺序表是用一组地址连续的存储单元依次存储线性表中的数据元素,从而使逻辑上相邻的两个元素在物理位置上也相邻;<br>
在顺序表中,每个元素的地址连续,类型相同,依次存放,可以根据索引随机存取;
![](https://raw.githubusercontent.com/matrix-johnjohn/kimo-docs/refs/heads/main/images/articles/server/c/data-struct/linearlist/4.linearlist.png)


## 顺序表结构定义
### 数组静态分配
编译的时候分配内存,大小固定;
````C
#define MAXSIZE 100

typedef struct SQList {
	ElemType data[MAXSIZE];
	int length;
} SQList;
````

### 数组动态分配
运行的时候手动分配内存,大小可变,但是动态分配增加数组长度的时候,将原数据复制到新的空间的时候,时间和空间的开销都很大;
````C
#define MAXSIZE 100

typedef struct SQList {
	ElemType *data;
	int length;
} SQList;
````

## 顺序表初始化
````C
#define MAXSIZE 100

SQList* initSequenceList(){

	ElemType* element = (ElemType*)malloc(sizeof(ElemType) * MAXSIZE);
	if (element==NULL){
		printf("InitSequenceList Function Memory allocation failed\n");
		exit(EXIT_FAILURE);
	}

	SQList *sqList=(SQList*)malloc(sizeof(SQList));
	if (sqList==NULL){
		printf("InitSequenceList Function Memory allocation failed\n");
		exit(EXIT_FAILURE);
	}

	sqList->data = element;
	sqList->length = 0;

	return sqList;
}
````

## 顺序表销毁
````C
void freeSequenceList(SQList* list){
	if (list != NULL){
		if (list->data != NULL){
			free(list->data);
		}
		free(list);
	}
}
````
## 顺序表清空
````C 
void clearSequenceList(SQList* list){
	if (list != NULL){
		list->length = 0;
	}
}
````

## 顺序表长度
````C
int getSequenceListLength(SQList* list){
	if (list != NULL){
		return list->length;
	}
	return -1;
}
````
