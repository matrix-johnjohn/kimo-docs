## 邻接矩阵
邻接矩阵(Adjacency Matrix)是表示顶点之间相邻关系的矩阵;
### 邻接矩阵的结构
```` cpp
#define max_weight -1
#define max_size 100

typedef struct Graph{
    char vexs[max_size];
    int arcs[max_size][max_size];
    int vexnum,arcnum;
}Graph;
````

### 邻接矩阵的初始化
```` cpp
int LocateGraph(Graph &G,char v){
    for(int i=0;i<G.vexnum;i++){
        if(G.vexs[i]==v)
            return i;
    }
    return -1;
};
Status CreateGraph(Graph& G){
    cin>>G.vexnum>>G.arcnum;
    for(int i=0;i<G.vexnum;i++)
        cin>>G.vexs[i];
    for(int i=0;i<G.vexnum;i++)
        for(int j=0;j<G.vexnum;j++)
            G.arcs[i][j]=max_weight;
    for(int k=0;k<G.arcnum;k++){
        char v1,v2;int w;
        cin>>v1>>v2>>w;
        int i=LocateGraph(G,v1);
        int j=LocateGraph(G,v2);
        G.arcs[i][j]=w;
        G.arcs[j][i]=w;
    };
    return OK;
};
````

## 邻接表
邻接表(Adjacency List)是图的一种`链式存储结构`,在邻接表中,对图中每个顶点`Vi`建立一个`单链表`,把`Vi`相邻接的顶点放在这个链表中;
![](https://raw.githubusercontent.com/matrix-johnjohn/kimo-docs/refs/heads/main/images/articles/server/c/data-struct/graph/01.graph.png)
### 表头结点表
表头结点包括`数据域`和`链域`两部分,`数据域`用于存储顶点`Vi`的名称或有关信息,`链域`指向链表中的第一个结点;
![](https://raw.githubusercontent.com/matrix-johnjohn/kimo-docs/refs/heads/main/images/articles/server/c/data-struct/graph/02.graph.png)
### 边结点表
边界点包括`邻接点域`,`数据域`,`链域`三部分组成,`邻接点域`是与顶点`Vi`邻接的点在图中的位置,`数据域`存储和边相关的信息,如权值等,`链域`是与顶点`Vi`邻接的下一条边的结点;
![](https://raw.githubusercontent.com/matrix-johnjohn/kimo-docs/refs/heads/main/images/articles/server/c/data-struct/graph/03.graph.png)
````cpp
typedef struct ArcNode{//边结点
    int adjvex;
    int info;
    struct ArcNode* nextarc;
}ArcNode;

typedef struct VNode{//表节点
    char data;
    struct ArcNode* firstarc;
}VNode,AdjList[max_size];

typedef struct Graph{//图结构
    AdjList vertiecs;
    int vexnum,arcnum;
}Graph;
````
