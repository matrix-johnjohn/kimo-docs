C++ 泛型编程是 C++ 的核心高级特性之一,它让你能写出与数据类型无关的通用代码,从而大幅提升代码的复用性、可维护性和类型安全性;

## 泛型函数
````cpp
template<typename T>
void swap_data(T &a,T &b){
    T temp=a;
    a=b;
    b=temp;
};
````

## 泛型类
````cpp
template<typename T,int MAXSIZE>
class Node{
    protected:
        T data[MAXSIZE];
        Node *next;
};
````
