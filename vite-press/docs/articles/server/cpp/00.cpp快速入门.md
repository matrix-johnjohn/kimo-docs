## 内存
### 开辟内存
`new`可以开辟一块内存空间,并返回该内存空间的指针;
````C
#include<iostream>

int main(){//带初始化
	int *p=new int(5);
	std::cout << *p << std::endl;
	return 0;
};

int main(){//无初始化
	int *p=new int;
	*p = 42;
	std::cout << *p << std::endl;
	return 0;
};
````
使用`new`开辟多个内存空间;
````cpp
#include<iostream>

int main(){
	int n=20;
  int *a=new int[n];
  for(int i=0;i<n;i++){
    a[i]=i;
  }
	return 0;
};
````


### 释放内存
`delete`将该地址下的内存释放干净,否则容易引发内存泄漏;
````cpp
#include<iostream>

int main(){
	int *p=new int(20);
	delete p;
	p = nullptr;
	return 0;
};
````
`delete`释放多个内存;
````cpp
#include<iostream>

int main(){
	int n=20;
  int *a=new int[n];
  for(int i=0;i<n;i++){
    a[i]=i;
  }
  delete[] a;
  a=nullptr;
	return 0;
};
````
