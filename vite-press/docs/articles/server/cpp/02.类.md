> C++ 在 C 语言的基础上增加了面向对象编程，C++ 支持面向对象程序设计。类是 C++ 的核心特性，通常被称为用户定义的类型。<br>类用于指定对象的形式，是一种用户自定义的数据类型，它是一种封装了数据和函数的组合。类中的数据称为成员变量，函数称为成员函数。类可以被看作是一种模板，可以用来创建具有相同属性和行为的多个对象。




## 类
在 C++ 语言中，`类`是用户`自定义类型`的基本构造单元，也是实现面向对象编程(Object-Oriented Programming, OOP)范式的核心语言特性;类提供了一种将`数据成员`与操作这些数据的`成员函数`进行`逻辑聚合与封装`的机制,从而支持信息隐藏、接口抽象和模块化设计;

### 成员函数外部定义
````cpp
class Box{
    protected:
        double width;
        double height;
    public:
        double getArea(void);
        void set(double wid,double hei);
};

double Box::getArea(void){
    return width*height;
};

void Box::set(double wid,double hei){
    width=wid;
    height=hei;
};

int main(){
    Box b1;//对象
    Box b2;

    b1.set(15,20);
    b2.set(10,10);

    cout<<b1.getArea()<<" "<<b2.getArea()<<endl;

    return 0;
};
````

### 成员函数内部定义
````cpp

    protected:
````

### 类访问修饰符
在 C++ 的类系统中，`访问修饰符`(Access Specifiers)是实现`封装`这一面向对象核心原则的关键语言特性;它们用于显式控制类成员在不同作用域下的可见性与可访问性,从而在编译期强制实施信息隐藏,保障类不变式的完整性;
```` cpp
class Box{
   public:
       //公有成员
   protected:
       // 受保护成员
   private:
       // 私有成员
};
````
| 修饰符 | 访问范围 | 典型用途  |
| ----- | ----- | ----- |
| public | all | 对外提供的接口函数(api)  |
| protected | 类内部,子类 | 继承体系使用的函数与数据 |
| private  | 仅子类 | 核心数据、不被随意修改的变量 | 

## 构造函数和析构函数
在c++的对象模型中,`析构函数`(Destructor)是与构造对称的核心特殊`成员函数`,在对象生命周期结束的时候执行清理逻辑,确保程序状态的一致性与`资源的安全回收`;
````cpp
#include<iostream>
#include<map>
using namespace std;

class Box{
    private:
        int index;
        double *history;
    protected:
        double width;
        double height;
    // 构造函数
    public:
        Box();
        Box(double wid,double hei);
    // 析构函数
    public:
        ~Box();
    
    public:
        double getArea();
        void set(double wid,double hei);
};

/**
 * 构造函数
 */
Box::Box(){
    history=new double[100];
    index=0;
};
Box::Box(double wid,double hei){
    width=wid;
    height=hei;
    history=new double[100];
    index=0;
};
/**
 * 析构函数
 */
Box::~Box(){
    for(int i=0;i<index;i++){
        cout<<history[i]<<" delete!"<<endl;
    };
    delete[] history;
};

double Box::getArea(){
    double area=width*height;
    history[index++]=area;
    return area;
};
void Box::set(double wid,double hei){
    width=wid;
    height=hei;
};

int main(){
    Box box(10,20);
    box.getArea();
    box.getArea();
    box.set(10.5,10);
    box.getArea();
    return 0;
};
````
