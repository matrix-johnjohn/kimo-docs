> C++ 在 C 语言的基础上增加了面向对象编程，C++ 支持面向对象程序设计。类是 C++ 的核心特性，通常被称为用户定义的类型。<br>类用于指定对象的形式，是一种用户自定义的数据类型，它是一种封装了数据和函数的组合。类中的数据称为成员变量，函数称为成员函数。类可以被看作是一种模板，可以用来创建具有相同属性和行为的多个对象。




## 类
在 C++ 语言中，`类`是用户`自定义类型`的基本构造单元，也是实现面向对象编程(Object-Oriented Programming, OOP)范式的核心语言特性;类提供了一种将`数据成员`与操作这些数据的`成员函数`进行`逻辑聚合与封装`的机制,从而支持信息隐藏、接口抽象和模块化设计;

### 成员函数外部定义
````cpp
class Box{
    protected:
        double width;
        double height;
    public:
        double getArea(void);
        void set(double wid,double hei);
};

double Box::getArea(void){
    return width*height;
};

void Box::set(double wid,double hei){
    width=wid;
    height=hei;
};

int main(){
    Box b1;//对象
    Box b2;

    b1.set(15,20);
    b2.set(10,10);

    cout<<b1.getArea()<<" "<<b2.getArea()<<endl;

    return 0;
};
````

### 成员函数内部定义
````cpp
class Box{
    protected:
        double width;

    public:
        double getArea(void){
            return width*height;

````

### 类访问修饰符
在 C++ 的类系统中，`访问修饰符`(Access Specifiers)是实现`封装`这一面向对象核心原则的关键语言特性;它们用于显式控制类成员在不同作用域下的可见性与可访问性,从而在编译期强制实施信息隐藏,保障类不变式的完整性;
```` cpp
class Box{
   public:
       //公有成员
   protected:
       // 受保护成员
   private:
       // 私有成员
};
````
| 修饰符 | 访问范围 | 典型用途  |
| ----- | ----- | ----- |
| public | all | 对外提供的接口函数(api)  |
| protected | 类内部,子类 | 继承体系使用的函数与数据 |
| private  | 仅子类 | 核心数据、不被随意修改的变量 | 

## 构造函数和析构函数
在c++的对象模型中,`析构函数`(Destructor)是与构造对称的核心特殊`成员函数`,在对象生命周期结束的时候执行清理逻辑,确保程序状态的一致性与`资源的安全回收`;
````cpp
class Box{
    public:
        int *width;
        int *height;
    public:
        Box();
        Box(int wid,int hei);
    public:
        ~Box();
    public:
        Box(const Box&b);
    public:
        int getArea(){
            return *(this->width)*(*this->height);
        }
};
//构造函数
Box::Box(){
    width=new int(0);
    height=new int(0);
};
//构造函数
Box::Box(int width,int height){
    this->width=new int(width);
    this->height=new int(height);
};
//析构函数
Box::~Box(){
    cout<<"Hello\n";
    delete this->width;
    delete this->height;
};

int main(){
    Box *b1=new Box(10,20);

    cout<<b1->getArea();

    delete b1;
    return 0;
};
````

## 拷贝构造函数
C++拷贝构造函数是一种特殊构造函数，用于用一个已存在的对象初始化新对象。其形参为本类类型的`常量引用（const Class&）`;若未显式定义，编译器会生成默认版本（浅拷贝）。当类包含指针或动态资源时，必须自定义拷贝构造函数实现深拷贝，否则会导致内存错误;
````cpp
#include<iostream>
using namespace std;

class Box{
    public:
        int *width;
        int *height;
    public:
        Box();
        Box(int wid,int hei);
    public:
        ~Box();
    public:
        Box(const Box&b);
};

//constructor
Box::Box(){
    width=new int(0);
    height=new int(0);
};
Box::Box(int wid,int hei){
    width=new int(wid);
    height=new int(hei);
};
//析构函数
Box::~Box(){
    delete width;
    delete height;
};
//拷贝构造函数
Box::Box(const Box&b){
    width=b.width;
    height=b.height;
};

int main(){
    Box box1(10,20);
    cout<<*box1.width<<" "<<*box1.height<<endl;
    return 0;
};
````

## this指针
this 是 C++ 中每个非静态成员函数隐含的常量指针,指向调用该成员函数的对象实例;
````cpp
//构造函数
Box::Box(int width,int height){
    this->width=new int(width);
    this->height=new int(height);
};
//析构函数
Box::~Box(){
    delete this->width;
    delete this->height;
};
````

## 类指针
类指针是指向类对象的指针,存储对象的内存地址,可通过它访问对象的成员或调用其方法;
````cpp
int main(){
    Box *b1=new Box(10,20);

    cout<<b1->getArea();

    delete b1;
    return 0;
};
````
