## 命名空间
命名空间的定义使用关键字namespace,为了调用带有命名空间的函数或变量,需要在前面加上命名空间的名称;
````cpp
namespace Utils{
    template<typename T>
    void swap_s(T &a,T &b){
        T temp=a;
        a=b;
        b=temp;
    };
};
int main(){
   int a=10,b=20;
   Utils::swap_s<int>(a,b);
   return 0;
}
````

## using指令
您可以使用 `using namespace` 指令,这样在使用命名空间时就可以不用在前面加上命名空间的名称;
````cpp
namespace Utils{
    template<typename T>
    void swap_s(T &a,T &b){
        T temp=a;
        a=b;
        b=temp;
    };
};
using namespace Utils;
int main(){
   int a=10,b=20;
   swap_s<int>(a,b);
   return 0;
}
````
