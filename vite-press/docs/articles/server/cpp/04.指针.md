## 内存
内存是计算机最重要的硬件之一,内存的最小单位是`字节byte`,每个`字节byte`都有一个唯一的地址,程序可以通过这个地址来访问内存中的数据;
![](https://raw.githubusercontent.com/matrix-johnjohn/kimo-docs/refs/heads/main/images/articles/server/c/pointer/1%E5%86%85%E5%AD%98.png)


### 栈内存
`栈内存`一般用来存储`局部变量`和函数的`参数`,分配和释放都是由编译器自动完成的,当程序执行完毕后这个变量所占用的内存会被自动释放,无需手动操作,但是栈内存通常只有几十兆,如果存储的数据量过大,就会造成`栈溢出`;
```` C
#include<stdio.h>
#include<stdlib.h>
#define MAX 10

int main(){
	int a = 20;
	return 0;
}
````
### 堆内存
堆内存通常会比栈内存大得多,但是分配和释放通常需要你通过`C`自带的api手动操作;主要是`malloc`和`free`;<br><br>
`malloc`主要用于`分配内存`,参数为`内存的大小`,返回值则是该`内存的地址`;<br><br>
`free`用于手动释放初始指针的内存空间,参数是需要被释放的初始化内存的地址,如果不手动清理,那么这块内存就会一直被占用,随着程序的运行,被占用的内存越来越多,最终就会导致`内存泄漏问题`;
````cpp
#include<iostream>

int main(){
    // malloc函数天生返回void*类型的值,这意味着它只返回内存地址,不会确定这块内存是用来存放什么类型的数据
	int *p=new int(5);

	delete p;//根据地址释放内存
	p = NULL;//避免指向不可用内存的指针
		
	return 0;
}
````

## 指针
指针是一个存储内存地址的变量,指针存储的值是内存中某个位置的地址,通过这个地址可以访问这块内存的数据,然后可以对其进行读取或修改;
![](https://raw.githubusercontent.com/matrix-johnjohn/kimo-docs/refs/heads/main/images/articles/server/c/pointer/2%E6%8C%87%E9%92%88.png)
```` C
#include<iostream>

int main(){
	int array[] = {1,2,3};
	int* p = array;
	printf("%p\n", p++);//000000C9359AF608
	printf("%p\n", p++);//000000C9359AF60C
	printf("%p\n", p++);//000000C9359AF610
	return 0;
}
````
