## 继承类
C++继承是面向对象编程的核心机制之一,允许派生类复用基类的成员,从而实现代码重用与层次化设计;
````cpp
/**
 * 基础类
 */
class Shape{
    protected:
        int width;
        int height;
    public:
        void setWidth(int width){
            this->width=width;
        };
        void setHeight(int height){
            this->height=height;
        };
};
/**
 * 派生类
 */
class Rectangle:public Shape{
    public:
        int getArea(){
            return this->width*this->height;
        };
};
````

## 虚函数
在基类中使用`virtual`关键字声明成员函数,派生类可选择性重写`(override)`;虚析构函数,确保在释放基类指针指向的派生类对象时能够正确调用派生类的析构函数,防止内存泄漏;
````cpp
/**
 * 基础类
 */
class Shape{
    protected:
        int width;
        int height;
    public:
        void setWidth(int width){
            this->width=width;
        };
        void setHeight(int height){
            this->height=height;
        };
    public:
        virtual int getArea(){//虚函数
            cout<<"[shape]:event call!"<<endl;
            return this->width*this->height;
        }
};
/**
 * 派生类
 */
class Rectangle:public Shape{
    public:
        int getArea()override{
            cout<<"[rectangle]:event call!"<<endl;
            return this->width*this->height;
        };
};
````
## 纯虚函数
纯虚函数是通过`virtual 返回类型 函数名() = 0`;声明的虚函数,它在基类中没有实现,强制派生类必须重写该函数;含有纯虚函数的类称为抽象类,不能实例化;
````cpp
/**
 * 基础类
 */
class Shape{
    protected:
        int width;
        int height;
    public:
        void setWidth(int width){
            this->width=width;
        };
        void setHeight(int height){
            this->height=height;
        };
    public:
        virtual int getArea()=0;//纯虚函数
};
/**
 * 派生类
 */
class Rectangle:public Shape{
    public:
        int getArea()override{
            return this->width*this->height;
        };
};
````
