## 引入
引用通常只是指针的语法糖,相比指针,引用只负责引用当前变量,它不会产生新的内存用于存储其路径;<br>
````cpp
#include<iostream>

int main(){
	int num=20;
  int &ref=num;
  ref=10;
	return 0;
};
````

````cpp
#include<iostream>

void increment(int &num){
  num++;
}

int main(){
	int num=20;
  increment(num);
  increment(num);
  increment(num);
	return 0;
};
````
