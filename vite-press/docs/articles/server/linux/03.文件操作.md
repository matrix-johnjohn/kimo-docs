## 文件系统
Linux 采用一切皆文件的设计哲学,无论是`普通文本`、`设备`、`进程信息`，还是`网络套接字`,在 Linux 中都被抽象为`文件`;而这些文件如何组织、存储、访问，则依赖于文件系统;
![](https://raw.githubusercontent.com/matrix-johnjohn/kimo-docs/refs/heads/main/images/articles/server/linux/file/01.file.png)

## 文件系统的目录结构

#### bin目录
`bin`目录专门用来存放二进制可执行文件,是系统最基本的命令程序,存放系统启动和运行所必需的、所有用户都能使用的最基本命令;
| 特性 | 详细说明 |
| --- | --- |
| 面向用户 | 普通用户与管理员 |
| 存放内容 | 系统命令(ls,rm,cp,mv) |
| 依赖关系	| 与根目录同一个分区 |

### boot目录
`boot`专门存放系统启动过程中必需的所有静态文件,你可以把它看成计算机开机时读取的`启动说明书`和`核心引擎`,`/boot`是 `Linux` 能够从`加电状态`顺利进入操作系统的关键所在;<br>
boot主要是为`内核`和`初始内存盘`提供一个安全、独立的存储位置,供引导加载程序（如 GRUB）在系统启动早期阶段访问;

### cdrom目录
`cdrom`是一个历史遗留的挂载点,过去用来临时挂载光盘(CD/DVD); 

### dev目录
在 Linux 中,一切皆文件,包括你的键盘、鼠标、硬盘、摄像头、甚至随机数生成器;而这些`设备文件`就统一放在/dev目录下;<br>

| 设备文件 |	对应的硬件/功能 |
| ------- | --------------  |
| /dev/sda |	第一块 SATA/SCSI 硬盘 |
| /dev/sda1 |	第一块硬盘的第一个分区 |
| /dev/tty | 终端 |
| /dev/null |	空 |
| /dev/random |	随机数生成器 |
| /dev/input/mouse0 |	第一个鼠标 |
| /dev/snd/ |	音频设备|

### etc目录
`/etc`是Linux系统的`配置中心`,几乎所有软件和系统服务的设置文件都放在这里;
|  文件/目录 | 作用 |
| --------- | --- |
| /etc/passwd |	存储用户账户基本信息 |
|/etc/shadow |	存储加密后的用户密码 |
| /etc/group |	用户组信息 |
| /etc/fstab |	定义系统启动时要自动挂载哪些磁盘分区 |
| /etc/hosts |	本地域名解析表 |
| /etc/resolv.conf| DNS 服务器配置(系统查找域名) |
| /etc/network/ 或 /etc/netplan/| 网络接口配置（静态 IP、网关等）|
| /etc/apt/sources.list	| Ubuntu/Debian 的软件源列表 |
| /etc/systemd/ |	systemd 服务的全局配置|
| /etc/nginx/、/etc/mysql/、/etc/ssh/ |	各类服务的专属配置目录|

### home目录
`/home`是所有普通用户的文件夹,每个用户的数据、配置、文档都存在自己的家目录里;

|  特性  |  说明  |
| ------ | ----- |
| 数据安全 | 重装系统时,如果/home是独立分区,你的所有个人文件和配置都能保留 |
| 多用户隔离 | Linux 是多用户系统,/home,让每个人都有自己的空间,互不干扰 |
| 环境定制 | 终端提示符、快捷键、软件偏好 |
