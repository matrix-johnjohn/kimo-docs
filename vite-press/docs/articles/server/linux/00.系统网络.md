## IP地址
IP 地址(Internet Protocol Address)是网络中设备的逻辑标识符,用于在TCP/IP网络中唯一标识一台主机或接口;<br>

在 IPv4 协议中,IP 地址是一个32位的无符号整数,通常以点分十进制形式表示,即把32位地址划分为4个8位段,每段转换为十进制数并用点号连接;
## 路由
在 Linux 系统中,每个`主机`都维护一张路由表,当系统需要发送一个 IP 数据包时,它会查询路由表,根据目的地址选择最匹配的出口接口和下一跳地址;
## DNS
DNS是将人类可读的域名(eg:`www.example.com`)转换为机器可识别的IP地址(eg:93.184.216.34)的分布式数据库系统;<br>
在 Linux 中,任何需要访问网络服务的应用程序(eg:curl、ssh、浏览器)都会依赖 DNS 解析来完成地址转换;
